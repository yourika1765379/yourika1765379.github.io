# 書架

同人活動の記録・作品公開用の個人サイトです。

## 概要

「書架」は、同人活動に関する作品や記録をまとめるために制作している個人サイトです。

主な目的は以下の通りです。

* 制作した作品の一覧表示
* 各作品ページの掲載
* 番外編SSなどの文章作品の公開
* 感想フォーム（Googleフォーム）の設置

## 公開環境

GitHub Pagesを利用して公開しています。

サーバーやデータベースは使用せず、ブラウザ上で動作する静的サイトとして制作しています。

## 使用技術

* HTML
* CSS
* JavaScript

## 対応環境

スマートフォンでの閲覧を主な対象としています。

## 起動・確認方法

ローカル環境では、HTMLファイルをブラウザで開くことで確認できます。

公開後はGitHub PagesのURLへアクセスすることで閲覧できます。

## ページ構成（予定）

* Home
    * サイトトップページ
* Profile
    * 制作者・活動についての紹介
* Library
    * 制作作品の一覧ページ
    * 各作品ページへの入口
        * Library内の各作品詳細ページ
        * 作品ごとの情報や本文を掲載
* Contact
    * 感想フォームなどの連絡ページ
